# AI for Health – SRIP 2026 Task

## Overview

This repository contains my progress for the **AI for Health task** as part of the **Summer Research Internship Program (SRIP) 2026** at IIT Gandhinagar.

The objective of this task is to explore how Artificial Intelligence and machine learning techniques can be applied to healthcare data to derive meaningful insights and support decision-making.

## Approach

The implementation is carried out using Python in a Jupyter/Colab notebook. The workflow followed in this project includes:

1. Loading and exploring the dataset
2. Data preprocessing and cleaning
3. Feature analysis and visualization
4. Building a basic machine learning model
5. Evaluating the model performance

The notebook demonstrates the fundamental pipeline of applying AI techniques to a healthcare-related dataset.
